# Аналитика продаж маркетплейса

## Описание проекта
Анализ продаж онлайн-маркетплейса за 2023 год.  
Включает сбор данных по API, ABC-анализ ассортимента, RFM-анализ клиентов и дашборд в Metabase.

---

## Технологии
- Python (pandas, matplotlib, sqlalchemy)
- PostgreSQL
- Metabase
- Docker
- Jupyter Notebook

---

## Особенности проекта

- Ежедневное обновление данных в 7:00 через планировщик (Docker / Планировщик задач Windows)
- Пароли и настройки вынесены в `.env` файл — безопасность
- Логирование операций с ротацией файлов (логи не засоряют диск)
- Проверка дублирующихся записей перед вставкой в БД
- Код работает на любом компьютере (относительные пути)
- Единый модуль `config.py` для подключения к базе данных

---
