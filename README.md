# Анализ продаж маркетплейса

> Полный цикл аналитического исследования: от сбора данных до бизнес-рекомендаций.

---

## О проекте

Цель — провести комплексный анализ продаж онлайн-маркетплейса (формата Ozon) и предложить конкретные бизнес-рекомендации по оптимизации ассортимента и увеличению LTV клиентов.

**Ключевые задачи:**
- Сбор и автоматическая загрузка данных через API
- Построение дашборда для оперативного мониторинга
- ABC-анализ ассортимента
- RFM-анализ клиентской базы
- Формулировка бизнес-выводов
- Создание презентации как краткого отчёта с выводами и рекомендациями для бизнеса

---

## Результаты

- **Объём данных:** 2 040 076 записей за 2023 год
- **ABC-анализ:** пороги 70/20/10, выявлены товары для вывода и промо
- **RFM-анализ:** выделено 6 сегментов клиентов (Champions, Loyal, At Risk, Lost и др.)
- **Аномалия:** обнаружен резкий спад в ноябре с последующим восстановлением
- **Дашборд:** Metabase с KPI, топами и анти-топами товаров

---

## Технологии

`Python` · `Pandas` · `SQLAlchemy` · `PostgreSQL` · `Metabase` · `Docker` · `Jupyter` · `Git`

---

## Особенности реализации

- Ежедневное обновление данных в 7:00 (планировщик задач)
- Пароли вынесены в `.env` (безопасность)
- Логирование с ротацией файлов
- Проверка дублей перед вставкой в БД
- Относительные пути — код работает на любом ПК
- Единый модуль `config.py` для подключения к БД
